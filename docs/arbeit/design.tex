\section{Design}

The game would work in 2 phases: the \textit{decisions phase} and the
\textit{simulation phase}.

During the decisions phase the player would set the values for various
decisions like how many production machines they choose to buy. Just like the
what we played during Economy Week, the interface was a thinly veiled Excel
table.
