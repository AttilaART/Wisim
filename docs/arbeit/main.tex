\section{Final Product}
\label{sec:final}

In the end, the product turned out pretty well, with me being able to add in most of the features I wanted to, at least for the beta.

In the game, which you can currently download onto your computer (see: Appendix), players have the ability to:

\begin{itemize}
	\item Develop, produce, market and sell their products,
	\item Upgrade their production lines to increase efficiency and productivity,
	\item Invest in research into their products and marketing,
	\item Predict future results using prediction mode and
	\item Play with their friends for extended periods.
\end{itemize}

\begin{figure}[h]
	\begin{center}
		\includegraphics[width=0.85\textwidth]{assets/wisimImage2.png}
	\end{center}
	\caption{Screenshot of game}
\end{figure}


Most of the main things I wanted to implement did get implemented; however, there were some things that had to be cut (for now) due to time constraints.

\subsection{Improved Marketing}

One major feature that was cut was a better marketing system along with loyalty. I wanted to have an advanced system where, instead
of just selecting how much money to invest in marketing and hiring more staff, the player would develop intricate marketing campaigns.
Each campaign would be able to target one or multiple personas so that you would be able to promote certain aspects to certain people.

The campaigns would also further involve the marketing employees, forcing players to be more selective about who they hire. A campaign
might need an employee that understands the target audience to be successful. Campaigns would also involve the player more in the running
of the company as well as encourage a smaller range of products (leading to more specialisation), as a player would get overwhelmed managing
dozens of products.

\subsection{Research Tree}

This feature would involve having a research tree with items that the player could research. These items would have to be researched by dedicated
R\&D personnel. When an item would be researched, the player would unlock various new production techniques as well as components that
would allow the company to specialise or run more efficiently.

The research tree would also slow down the dominance of game winners, since they would have to wait or spend more resources to
become able to properly scale.

\subsection{Automatic Win Conditions}

The game currently doesn't have win conditions built-in. This means that the game would usually end when the players don't want to play anymore.
This should change: players should be able to choose from a variety of win conditions before starting a game. When
the conditions are met, the game ends and players are given the option to also keep playing. Win conditions might include:

\begin{itemize}
	\item Most valuable company after a set amount of rounds
	\item Largest market share after a set amount of rounds
	\item First company to 100'000'000 CHF valuation
	\item First company to sell 10'000'000 CHF per month
\end{itemize}

\subsection{Download the Game}

If you want to try the game out for yourself, you can download the game files by going to the URL below, clicking on
"Releases" on the right, then downloading the correct binary for your device.

\href{https://github.com/AttilaART/Wisim}{https://github.com/AttilaART/Wisim}

{\small For windows download the ".exe" file, for newer Macs download the "darwin-arm64" version, for older Macs
	download the "darwin-amd64" version and for Linux download the "linux" version.}

MacOS and Linux users may have to make the file executable by running the command displayed below (replace
"wisim-linux-amd64" with the name of the file you downloaded):

\begin{figure}[h]
	\begin{center}
		\includegraphics[width=0.85\textwidth]{assets/linuxmakeexecutable.png}
	\end{center}
\end{figure}

After starting the program, a browser window should open, which shows the game's main menu. If this doesn't happen, navigate to
\href{http://localhost:3000}{http://localhost:3000} and have fun!
