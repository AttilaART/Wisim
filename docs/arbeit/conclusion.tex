\section{Conclusion and Future}

I am quite happy with the state of Wisim. Though the game is in a playable
state, it is not ready yet for a full release, not until after the features that I outlined
in chapter \ref{sec:final} are ready.
I then plan to release it on Steam when it's ready.

This project has taught me a lot, from game design to advanced optimisations to time management. This has been my first
long-term software project and while I can't say that it couldn't have gone better, it is an homage to what you can do with
hard work and dedication.
