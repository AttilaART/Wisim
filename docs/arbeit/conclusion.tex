\section{Conclusion and Future}

This project has taught me a lot, from game design to advanced optimisations to time management, there are few things
that I \textit{didn't} learn from this project.

I am quite happy with the result of Wisim, however I can't call it a finished product yet. The game is in a playable
state, but I don't think it's ready for a release yet. I plan to continue working on the game until it is truly ready, I
then plan to release it on Steam.
