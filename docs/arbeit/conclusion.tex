\section{Conclusion and Future}

I am quite happy with the state of Wisim, however I can't call it a finished product yet. The game is in a playable
state, but I don't think it's ready for a full release yet. I plan to continue working on the game until it is truly ready,
or at least until after the features that I outlined in chapter \ref{sec:final} are ready, I
then plan to release it on Steam.

This project has taught me a lot, from game design to advanced optimisations to time management. This has been my first
long-term software project and while I can't say that it couldn't have gone better, it is an homage to what you can do with
hard work and dedication.
